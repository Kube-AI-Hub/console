# 删除负载（L3）

[子模块需求](./_index.md)

## 概述

行操作的「删除」与多选的「批量删除」，确认对话框列出对象名。

## 用户故事

### US1 - 删掉不再需要的负载 (Priority: P2)

作为 **项目运维**，我希望 **确认后删除，并可一次删多个**，以便 **清理项目**。

**Independent Test**：创建一个一次性部署并删除，核对列表不再出现。

## 验收场景

- **AC-L3-KUBE-FRONTEND-APP_WORKLOADS-DELETE-01** — 已知列表有一行，当删除并确认，则对话框关闭且该行消失。

## 设计目标

与配置字典相同的删除交互与自清理约定。

## 约束与边界

- 删除走原生端点，按 API 组。
- 批量删除逐个下发，失败靠刷新暴露。

## UI 交互设计

确认对话框显示对象名与后果，确认按钮为危险色。

## 文案与校验

- 确认按钮「删除」；取消「取消」。

## 边界情况

- 失败时保留对话框并显示错误。

## 明确不做

- 不做回收站与恢复。

## 假设

- 删除后由列表重新拉取反映结果。

## 验收用例

- `TC-L3-KUBE-FRONTEND-APP_WORKLOADS-DELETE-01`

## 功能需求

- **FR-L3-KUBE-FRONTEND-APP_WORKLOADS-DELETE-01** — 单个删除。
- **FR-L3-KUBE-FRONTEND-APP_WORKLOADS-DELETE-02** — 批量删除。

## 成功标准

- **SC-L3-KUBE-FRONTEND-APP_WORKLOADS-DELETE-01** — 删除后列表 2 秒内不再包含该对象。
