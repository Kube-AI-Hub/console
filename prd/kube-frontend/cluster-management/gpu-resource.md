# GPU 资源监控（L3）

[子模块需求](./_index.md)

## 概述

集群级 GPU 资源趋势：在 1 小时 / 6 小时 / 24 小时窗口里看 **GPU 利用率**与**显存利用率**随时间的变化，并在有数据时给出「已分配 / 总数」的概览。数据来自集群监控 API 的区间查询，用服务端已定义的命名指标（`cluster_gpu_utilization`、`cluster_gpu_memory_utilisation`）；页面只把比例换算成百分比并画图，不拼 PromQL、不自己聚合。

没有 GPU 监控数据时显示明确的空态说明——空结果不是错误：指标由 gpu-agent 与监控后端提供，缺失时接口返回 200 + 空结果。

## 用户故事

### US1 - 集群运维看 GPU 利用率与显存随时间的走势

作为 **集群运维**，我希望 **在集群 GPU 资源页选择时间窗口看利用率与显存趋势**，以便 **判断算力是否吃满、显存是否接近上限，以及最近一次变更后是否变差**。

**Independent Test**：打开 `/clusters/host/gpu-resource`，三档窗口可切换；窗口内有数据时图表出现且柱数 > 0，无数据时显示空态说明。

## 验收场景

- **AC-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-GPU_RESOURCE-01** — 已知集群接入了监控后端与 GPU 指标，当打开 GPU 资源监控页，则默认 1 小时窗口展示 GPU 利用率与显存利用率两条趋势（有数据时每张图柱数 > 0、数值为百分比），可切换到 6 小时 / 24 小时且当前窗口标记与请求区间、采样步长同步变化；当所选窗口没有任何 GPU 指标数据时，显示明确的空态说明，而不是空白图表或错误页。

## 设计目标

1. 一屏回答「GPU 忙不忙、显存紧不紧」。
2. 窗口切换同时改变区间与采样步长：曲线可读，请求量可控。
3. 「无数据」与「利用率为 0」必须能区分。

## 约束与边界

- 数据只来自监控 API 的区间查询（宪法 C1）；页面不直连 Prometheus、不拼 PromQL。
- 只使用服务端已定义的命名指标；指标名口径属于 ks-apiserver，不在页面里另起一套。
- 只读：不提供导出、不提供告警配置。
- 不引入图表库：两条 60–100 点的序列用内联 SVG 柱图足够。
- 窗口固定三档：1h（60s 步长）、6h（5m）、24h（15m）。

## UI 交互设计

- 顶部：标题 + 说明；右对齐三档窗口按钮，当前档用主色并按 `aria-pressed` 标记。
- 概览条：已分配 X / 共 T 张 GPU（只在计数指标有数据时显示）。
- 两张趋势卡（窄屏单列、宽屏两列）：标题 + 当前值；柱状图；下方最小 / 最大 / 当前。
- 空态：整块说明（窗口内无任何 GPU 指标）+ 依赖提示；只有一个指标无数据时，只在该卡内显示空态文案，页面不整块空。

## 文案与校验

- 窗口：最近 1 小时 / 最近 6 小时 / 最近 24 小时。
- 指标：GPU 利用率 / 显存利用率。
- 概览：已分配 {allocated} / 共 {total} 张 GPU。
- 空态：该时间范围内没有 GPU 监控数据。 依赖提示：GPU 监控依赖 gpu-agent 与监控后端；确认它们就绪后重试。
- 数值一律百分比取整（接口比例 ×100）。

## 边界情况

- 监控接口失败：错误面板 + 重试，不显示上一次的陈旧图表。
- 指标存在但窗口内没有采样点（采集刚重启、窗口太早）：空态。
- 只有一个指标有数据：该卡绘图，另一卡显示空态文案；页面不作为整块空态。
- 有数据但利用率为 0（集群空闲）：显示 0% 与零高度柱，不退化成空态——空态只看「有没有点」。
- 计数指标缺失：概览条不渲染，趋势照常。
- 时间参数：接口要秒级时间戳；窗口在选定瞬间折算成绝对区间，避免每次渲染都移动窗口。

## 功能需求

- **FR-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-GPU_RESOURCE-01** — 按三档窗口读取集群 GPU 利用率与显存利用率的区间指标并绘成趋势。
- **FR-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-GPU_RESOURCE-02** — 窗口内没有指标数据时展示明确空态；接口失败时展示错误与重试。

## 成功标准

- **SC-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-GPU_RESOURCE-01** — 三档窗口可切换且当前窗口标记随之变化；窗口内有数据时柱数 > 0；无数据时出现空态说明。

## 明确不做

- 单卡 / 节点级 GPU 指标（`gpu_card_*` 需要 `gpu_uuid`，属于单卡监控与排名页）。
- GPU 告警规则配置（属于监控告警模块）。
- 导出 CSV / 图片、拖拽缩放（会需要图表库，见技术方案的取舍）。
- 7 天窗口：当前三档已覆盖排障窗口，更长周期留给后续。

## 假设

- 集群启用监控后端，且 gpu-agent 在写 GPU 指标（`cluster:gpu_*` recording rules 存在）。不满足时页面显示空态，不报错。
