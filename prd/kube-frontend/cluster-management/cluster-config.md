# 集群级配置（L3）

[子模块需求](./_index.md)

## 概述

集群里全部项目中的保密字典、配置字典与服务账号的跨项目只读列表，每行带**项目列**，名称链到该项目内的详情页。三页分别是 `/kube-frontend/clusters/<cluster>/secrets`、`.../configmaps`、`.../serviceaccounts`，从集群侧栏「配置」分组可达。

项目级页只能回答「这个项目里有什么」；集群管理员排障的第一步常是反过来的——这个 Secret 在哪个项目、哪几个项目还留着一份过期配置、某个服务账号有没有复制到新项目。这三种对象的读取本来就是 Kubernetes 的原生能力（全命名空间 list 不需要聚合接口），老 console 也一直有这三页。

## 用户故事

### US1 - 跨项目定位一份配置 (Priority: P1)

作为 **集群管理员**，我希望 **不进入具体项目就按名称检索集群里的保密字典 / 配置字典 / 服务账号**，以便 **先确认对象属于哪个项目，再跳到该项目里处理**。

**Independent Test**：打开集群级保密字典页，核对行数等于 `min(20, total)`、项目列等于对象命名空间、名称链接含 `/projects/<namespace>/secrets/<name>`；对配置字典与服务账号各重复一次。

## 验收场景

- **AC-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-CLUSTER_CONFIG-01** — 已知集群里有保密字典、配置字典与服务账号，当从集群侧栏「配置」分组依次打开三页，则每页都显示名称（链接到该对象所属项目内的详情页）、项目、资源专属列（保密字典的类型与字段数、配置字典的字段数、服务账号的保密字典数）与创建时间；每页行数等于 `min(20, total)`；项目列等于对象命名空间；名称链接形如 `/kube-frontend/<workspace>/clusters/<cluster>/projects/<namespace>/{secrets,configmaps,serviceaccounts}/<name>`；按名称的服务端搜索与每页 20 条的分页可用。

## 设计目标

1. 三页共用一套列语义、链接规则与搜索/分页交互，差异只在资源本身与专属计数列。
2. 只读：写操作全部回项目作用域，集群页不提供第二套编辑入口。
3. 集群级集合的首屏比项目级慢，页面必须给出加载态并允许 60 秒以上的等待。

## 约束与边界

- 读 `/kapis/resources.kubesphere.io/v1alpha3/{secrets,configmaps,serviceaccounts}`（无 namespace 段 = 跨项目）；不逐项目循环请求再合并。
- 服务端只接受 `limit` / `page` / `sortBy` / `ascending` / `name`；不做 `fieldSelector` 筛选（kapis 代理忽略它，见迁移计划 §52）。
- 项目 → 企业空间由命名空间列表一次性建立索引；解析不到时链接回落 `public`。
- 创建、编辑、删除、改角色均不在本组页面。

## UI 交互设计

- 侧栏「配置」分组下三项：保密字典、配置字典、服务账号；页内没有项目切换器（集群作用域）。
- 列表：关键字搜索框（防抖后触发服务端搜索）、名称与创建时间可排序、底部分页。
- 保密字典列：名称（链接）、项目、类型、字段数、创建时间；配置字典列：名称（链接）、项目、字段数、创建时间；服务账号列：名称（链接）、项目、保密字典、创建时间。
- 窄屏依次折叠项目列之外的后几列；项目列在 `md` 以下也折叠。
- 空态：没有对象或当前条件下没有对象；失败：错误面板 + 重试。

## 文案与校验

- 标题沿用 `cluster.config.*`：保密字典 / 配置字典 / 服务账号；描述统一为「集群内全部对象，按项目列出。」
- 列标题沿用已有资源词典：名称、项目、类型、字段数、保密字典、创建时间；未知的 Secret 类型原样显示类型字符串。
- 空值显示 `-`；计数为 0 时显示 0，不显示 `-`（0 是答案）。

## 边界情况

- 同名对象出现在多个项目（每个命名空间都有的 `kube-root-ca.crt` 是最常见的例子）：行句柄用「项目/名称」，不用名称单键，避免表格键重复与自动化定位歧义。
- Secret 没有 `type`：按 kube-apiserver 的默认值显示 `Opaque`。
- 命名空间读失败或对象所属命名空间已不存在：链接回落 `public`，列表本身仍可读。
- 搜索无结果：行数为 0 并显示空态，而不是继续显示上一页数据。

## 功能需求

- **FR-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-CLUSTER_CONFIG-01** — 保密字典、配置字典、服务账号三页的跨项目只读列表。
- **FR-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-CLUSTER_CONFIG-02** — 项目列、项目内详情链接，以及服务端关键字搜索与分页。

## 成功标准

- **SC-L3-KUBE-FRONTEND-CLUSTER_MANAGEMENT-CLUSTER_CONFIG-01** — 三页行数 = `min(20, total)`；项目列 = 对象命名空间；名称链接含 workspace、项目与资源段；输入关键字与翻页都产生新的服务端请求。

## 明确不做

- 集群级创建 / 编辑 / 删除 / 改角色：写操作回项目作用域，避免同一对象两个编辑入口。
- 按项目、按类型的筛选下拉：kapis 代理不支持 `fieldSelector`，放一个不生效的控件比不放更差。
- 列出自定义资源类型的配置对象。

## 假设

- 项目归属由命名空间的 `kubesphere.io/workspace` 标签给出；缺失时按 `public` 处理。
- 集群里至少有一个项目、每页请求在 60 秒内返回。
