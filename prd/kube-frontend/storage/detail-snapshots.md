# 存储详情的快照页签（L3）

[子模块需求](./_index.md)

## 概述

存储卷（PVC）详情新增「属性 / 快照」两个页签。快照页签只读地列出从该存储卷创建的快照：名称、就绪状态、大小、创建时间。快照详情（VolumeSnapshot）不显示该页签。

B200 上 VolumeSnapshot CRD 已安装（`snapshot.storage.k8s.io/v1` 可列出），但对象为 0，所以「有数据的表格」在本集群不可用；交付必须让空态明确——显示「还没有快照」，而不是永远转圈的空白或空白区块。

## 用户故事

### US1 - 从存储卷详情查看它的快照 (Priority: P2)

作为 **项目成员**，我希望 **在存储卷详情里切到「快照」页签看到该卷的快照**，以便 **判断能不能从快照恢复、最近一次副本有多新**，而不必回到卷列表按名字再找一遍。

**Independent Test**：打开一个存储卷详情，切到「快照」页签；有快照时逐行显示名称/状态/大小/创建时间，没有快照时显示「还没有快照」空态。

## 验收场景

- **AC-L3-KUBE-FRONTEND-STORAGE-DETAIL_SNAPSHOTS-01** — 已知打开一个存储卷的详情，当切到「快照」页签，则列出从该卷创建的快照的名称、就绪状态、大小与创建时间；该卷没有快照时显示「还没有快照」空态（集群已装 VolumeSnapshot CRD 但对象为 0 时也是这个空态，而不是加载中）；页签只读，不提供创建或删除快照。

## 设计目标

1. 在存储卷详情的上下文里回答「这个卷有哪些副本、能不能恢复」。
2. 空态可解释：CRD 已装但没有对象时必须明确说明，不能留白或一直转圈。
3. 只读：创建/删除快照属于写操作，不在本页。

## 约束与边界

- 快照按**命名空间**读取（`/kapis/resources.kubesphere.io/v1alpha3/namespaces/<ns>/volumesnapshots`，成员集群在组名后加 `clusters/<id>/` 段），一次 `limit=-1`。
- 只列**本存储卷**的快照：按 `spec.source.persistentVolumeClaimName` 过滤，不是该项目的全部快照。
- 页签只在 PVC 详情出现；快照详情没有「快照」页签。
- 只读：页签内没有创建、删除、编辑入口。

## UI 交互设计

- 存储卷详情标题下是页签条：属性 / 快照；属性页签保持原有属性块。快照页签为表格（名称、状态、大小、创建时间），名称为链接，指向该快照的详情页。
- 快照详情（`volumesnapshots`）保持单页属性，不出现页签条。
- 加载中骨架；读取失败给说明 + 重试；0 条给空态。

## 文案与校验

- 页签标题：快照。
- 列：名称、状态、大小、创建时间；状态沿用存储列表的中文（就绪 / 等待中）。
- 空态：标题「还没有快照」，说明「为该存储卷创建快照后，这里会列出它们。」
- 读取失败：「快照列表读取失败。」+ 重试。

## 边界情况

- 快照 CRD 已安装、对象为 0：显示空态（B200 现状）。
- 快照尚未就绪：状态显示「等待中」，大小为空时显示 `-`。
- 快照的来源卷已不存在：只要 `source.persistentVolumeClaimName` 等于当前卷名就仍列出。
- 快照接口失败（权限或 CRD 未装）：页签内给失败说明与重试，不影响属性页签。
- 打开的是快照详情：不渲染快照页签。

## 功能需求

- **FR-L3-KUBE-FRONTEND-STORAGE-DETAIL_SNAPSHOTS-01** — 存储卷详情提供「快照」只读页签，按来源卷过滤，含明确空态与失败重试。
- **FR-L3-KUBE-FRONTEND-STORAGE-DETAIL_SNAPSHOTS-02** — 快照详情不提供快照页签。

## 成功标准

- **SC-L3-KUBE-FRONTEND-STORAGE-DETAIL_SNAPSHOTS-01** — 快照页签行数 = 命名空间内 `spec.source.persistentVolumeClaimName` 等于当前卷的快照数；为 0 时显示「还没有快照」空态。

## 明确不做

- 创建 / 删除快照（写操作，属快照管理；B200 当前写类 webhook 故障也使这些操作不可用）。
- 快照内容的嵌套查看（由快照内容页面负责）。
- 按时间排序/筛选快照。

## 假设

- 集群已安装 VolumeSnapshot CRD；未安装时接口报错并由页签显示失败说明。
- 快照的 `spec.source.persistentVolumeClaimName` 是判定归属的字段。
