# 保密字典 · 移动端适配（L3）

## 概述

窄屏（< `640px`）下列表折叠次要列，侧栏收进抽屉，触控目标不小于 44×44px。保密字典比配置字典多一列类型，因此折叠顺序更重要：名称之后先保字段数还是类型，取决于在小屏上「一眼认清这是什么」的价值。

## 用户故事

### US1 - 作为在手机上排查问题的运维，看清有哪几条 Secret 以及它们是什么类型

**Independent Test**：在 375×667 视口打开列表，页面无横向滚动；能看到名称与描述；「字段数」列隐藏，「类型」列在手机上隐藏（`lg` 以下），但名称单元格仍然可点进详情。

## 验收场景

- **AC-L3-KUBE-FRONTEND-SECRETS-MOBILE-01** — Given 375px 宽视口打开保密字典列表，When 等待加载完成，Then 页面 `document.scrollingElement.scrollWidth` 不超过视口宽度、导航收进抽屉（`shell:nav-toggle` 存在）、搜索框与创建按钮高度不小于 44px，列表只显示名称列（类型、字段数、创建时间折叠）。

## 设计目标

- 「能滚动」不等于可用：主要任务是「找到一条并点开」，因此名称列必须一直在。
- 断点是决策而不是继承默认值：每条列的 `hideBelow` 都在设计里写明。

## 约束与边界

- 断点：`fieldCount` → `md`（<768 隐藏），`type`、`createTime` → `lg`（<1024 隐藏），`project` → `xl`（<1280 隐藏）。
- 使用 `100dvh` 而不是 `100vh`（地址栏收起时不跳变），横滑容器加 `overscroll-x-contain`。
- 详情页在窄屏堆叠：属性区单列，TLS 两块上下排列。

## UI 交互设计

- 侧栏改为抽屉，通过头部汉堡按钮（`shell:nav-toggle`）打开，选中项后自动关闭。
- 工具条纵向堆叠，搜索框占满宽度。
- 分页控件保持 44px 触控高度。

## 文案与校验

- 同桌面视口。

## 边界情况

- 超长别名：名称列截断并保留 `title`。
- 虚拟键盘弹出时搜索框不遮挡结果（输入框在页首，列表随页面滚动）。

## 功能需求

- **FR-L3-KUBE-FRONTEND-SECRETS-MOBILE-01** — 375px 宽下不得出现横向滚动。
- **FR-L3-KUBE-FRONTEND-SECRETS-MOBILE-02** — 主要触控目标不小于 44×44px。

## 成功标准

- **SC-L3-KUBE-FRONTEND-SECRETS-MOBILE-01** — 375px 视口下 `scrollWidth <= innerWidth`，且能在两步内打开任意一条详情。

## 明确不做

- 不做专用的移动端卡片布局（列表复用同一套表格，只是折叠列）。
- 不做手势（左滑删除等）。

## 假设

- 移动端浏览器支持 `dvh`；不支持时回退到 `vh`。
