# 集群配置字典（L2）

## 概述

集群管理下的配置字典页。它与项目级配置字典（`prd/kube-frontend/configmaps/`）是**两个页面**，不是同一个页面的两种 URL：老 console 里它们各自有一份列定义、一份操作集，且集群级多一列「项目」、创建时必须选项目、联邦对象只读。

入口：`/kube-frontend/clusters/:cluster/configmaps`，从顶部「平台管理 → 集群管理 → 配置 → 配置字典」进入。

## 用户故事

### US1 - 作为集群运维，一次看清集群里所有项目的配置

**Independent Test**：进入页面，列表跨多个项目返回对象；「项目」列显示每个对象所属的项目；按名称搜索 `kubeconfig` 能命中其他项目里的对象。

### US2 - 作为集群运维，就地修正某个项目里的一条配置

**Independent Test**：在列表里对一条对象打开「编辑设置」修改键值并保存，刷新后值已更新；再用 `kubectl -n <项目> get configmap <名称> -o yaml` 确认与页面一致。

### US3 - 作为集群运维，创建到指定项目

**Independent Test**：点击「创建」，在第一步选择一个项目并填名称，提交后在列表里按该项目筛选能看到新对象。

## 验收场景

- **AC-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-01** — Given 集群中多个项目都有 ConfigMap，When 打开集群配置字典，Then 表头为 名称 / 项目 / 字段 / 创建时间，首行来自任意项目且「项目」列非空；分页总数与 `kubectl get configmap -A` 的条目数一致。

## 页面结构

| 区域 | 内容 | 说明 |
|---|---|---|
| 页头 | 标题「配置字典」、一句说明 | 与项目级区分开 |
| 工具条 | 搜索框、项目筛选、「创建」、「批量删除」 | 项目筛选默认「全部项目」 |
| 列表 | 名称 / 项目 / 字段 / 创建时间 | 「项目」列在任何宽度都显示 |
| 分页 | 页码与总数 | 仅在 `ready` 态出现 |
| 详情 | 属性区 + `Data` 分区 + 四个操作 | 联邦对象只读 |

## 功能点

- 集群配置字典列表（`list`）
- 按名称搜索（`search`）
- 集群配置字典详情（`detail`）
- 创建配置字典（`create`）
- 编辑配置字典（`edit`）
- 删除配置字典（`delete`）
- 智能体可操作性（`ai-surface`）
- 移动端适配（`mobile`）

## 异常态

- 无权限（403）：显示不可重试的说明。
- 上游失败：显示错误与「重试」。
- 空集合：说明在任一项目中创建后会出现在这里。
- 深链接缺少 `?namespace=`：详情页无法定位对象时显示「未找到」，并给回列表的链接。

## 设计目标

- 共享：列表状态机、三个编辑弹窗、删除弹窗与详情布局与项目级同一份实现。
- 差异只出现在三处：多一列「项目」、读跨项目集合、创建时必须选项目。
- 「项目」列承担去歧义：ConfigMap 名称只在项目内唯一。

## 约束与边界

- 读走 kapis，写走 `/api/v1`；跨项目读取走不带作用域段的集合端点。
- 写请求必须带对象自身的项目，不能使用列表的筛选值。
- 联邦对象只读。
- 分页大小固定 10，与项目级一致。

## UI 交互设计

- 入口在顶部「平台管理 → 集群管理 → 配置 → 配置字典」。
- 项目筛选默认「全部项目」，一步可收窄到单个项目。
- 详情留在集群管理区域内，项目通过查询串携带。

## 功能需求

- FR-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-01：跨项目浏览集群内全部 ConfigMap。
- FR-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-02：对单条对象完成编辑信息、编辑 YAML、编辑设置与删除。
- FR-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-03：创建时指定目标项目。

## 成功标准

- SC-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-01：页面总数与 `kubectl get configmap -A` 一致。
- SC-FULL-KUBE-FRONTEND-CLUSTER-CONFIGMAPS-02：任何写操作都不影响其他项目的同名对象。

## 明确不做

- 不把集群级与项目级合并成一个页面。
- 不做跨项目批量删除。
- 不做列显示/隐藏自定义。

## 假设

- 用户是集群管理员，对目标项目有相应权限。
- 服务端返回的 `totalItems` 反映全集。

## 验收用例

- `TC-FULL-KUBE-FRONTEND-CLUSTER_CONFIGMAPS-01`
