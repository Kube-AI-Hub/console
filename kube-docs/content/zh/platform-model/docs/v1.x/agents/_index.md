## 什么是智能体模板

智能体模板仓库用 Git 保存**可供复用的智能体定义**，种子文件为 `AGENT.md`。

模板的价值在于把一份配好的智能体定义变成可分享的资产：智能体工坊的工作流画布上，**子智能体** 节点可以委派到已上传的模板，并限定它的工具与知识范围，从而用多个角色协作完成一条业务流程。

## 列表

进入 **数据与资产 → 智能体模板**（`/agents`）。

- 顶部是搜索与排序，另有 **全部 / 个人** 范围切换与 **+ 新建**。
- 左侧是标签筛选，主区是卡片网格；点击卡片进入详情。

可见范围与模型库同一把尺子：**公共租户的公开仓库 ∪ 当前租户的仓库**。详情与列表同一把尺子。

## 新建模板

新建页的查询参数为 `type=agents`，表单与代码仓库同构：

| 参数 | 说明 |
|------|------|
| 所有者 | 默认为当前登录用户；已加入组织时可切换 |
| 英文名 | 作为仓库路径的一部分，创建后不可更改 |
| 别名 / 描述 | 选填 |
| 可见性 | 公开或私有 |
| 来源地址 | 填写 Git URL 时自动配置镜像同步 |

## 详情

进入 `/agents/:namespace/:name`，默认页展示 README、元数据与下载统计。顶部页签包括 **概览 / 卡片**、**文件** 与 **设置**，与技能仓库同构。

## 在智能体里使用模板

在服务专家工作流模式的画布上：

1. 从节点库的 **基础节点** Tab 加入一个 **子智能体** 节点。
2. 在属性面板里选择已上传的智能体模板。
3. 按需限定这个子智能体可用的工具与知识范围。

规划节点负责拆分任务，子智能体节点负责执行各自的部分，形成多角色协作。

## 管理后台

智能体模板在管理后台的资产管理中可搜索、查看可见性与权重，并支持单条 / 批量删除。
