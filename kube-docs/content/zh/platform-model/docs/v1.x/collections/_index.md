## 什么是合集

合集把模型、数据集、代码、用户空间等**公开项目**收成一个专题，方便分享与浏览。

合集本身**不是 Git 仓库**，只保存元数据与项目引用，因此不占存储、不需要上传文件。

典型用法：把一条业务链路相关的模型、数据集和推理代码收成一个「智能客服方案」合集，分享给同事或客户。

## 列表

进入 **数据与资产 → 合集**（`/collections`）。

- 卡片展示**主题色、标题与简介**。
- 顶部搜索按名称关键字过滤；另有 **+ 新建**。
- 点击卡片进入详情。

## 新建合集

| 参数 | 说明 |
|------|------|
| 名称 | 2–70 个字符，**创建后不可更改** |
| 简介 | 一句话说明这个专题包含什么 |
| 主题色 | 淡紫色 / 淡绿色 / 淡橙色 |

## 详情

合集详情有两个页签：

- **项目**：列出合集内的模型、数据集、代码与用户空间。空合集有「添加项目」引导。
- **设置**：修改简介与主题色。

两种添加项目的方式：

1. 在合集详情的 **项目** 页签里添加。
2. 从各个仓库详情页的 **加入合集** 操作里选择目标合集。

移除项目同样在合集详情的项目列表里操作。

## 可见性

合集只收**公开项目**。项目本身的可见性不因加入合集而改变，进入项目详情仍按该项目自己的权限判断。
