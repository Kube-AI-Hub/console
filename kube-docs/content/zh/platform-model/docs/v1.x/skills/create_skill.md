## 入口

两种方式都可以：

- 在技能列表点 **+ 新建**。
- 直接打开 `/new?type=skill`。旧的 `/skills/new` 会重定向到这里。

## 填写表单

| 参数 | 是否必填 | 说明 |
|------|----------|------|
| 所有者 | 是 | 默认为当前登录用户；已加入组织时可切换为组织名 |
| 英文名 | 是 | 作为仓库路径的一部分，**创建后不可更改**；长度 2–64 个字符，以字母开头、字母或数字结尾，仅支持字母、数字、`-`、`_`、`.` |
| 别名 | 否 | 中文名或友好名称 |
| 描述 | 否 | 简要说明这个技能解决什么问题 |
| 可见性 | 是 | **公开**：门户中同租户成员可见；**私有**：仅授权用户可见 |
| 来源地址 | 否 | 填写 Git URL 时创建完成后自动配置镜像同步；留空则创建空仓库 |
| 压缩包 | 否 | 上传压缩包一次性导入文件 |

提交成功后平台生成 Git 仓库与 `README.md`。

## 初始化文件

创建后有两种上传方式：

- **网页上传**：进入详情页的 **文件** 页签，新建文件或上传。
- **Git 上传**：用 HTTPS、SSH 或命令行把文件推送到仓库。

技能的定义写在技能文件里，供智能体或工作流调用。建议在 `README.md` 里写清这个技能做什么、需要什么输入、产出什么。
