## 什么是技能仓库

技能仓库托管**可供智能体或工作流复用**的技能定义与文件。技能是一种能力资产：写一次，可以被多个智能体引用，升级一次即对所有引用它的智能体生效。

技能在智能体工坊里被引用：数字分身与服务专家的「技能」分区从平台技能里挑选，工作流画布的「能力节点」也能直接加一个已绑定的技能节点。

## 列表

进入 **数据与资产 → 技能**（`/skills`）。

- 顶部是搜索与排序，另有 **全部 / 个人** 范围切换（默认「全部」，未登录不展示）与 **+ 新建**。
- 左侧是标签筛选，主区是卡片网格。
- 点击卡片进入详情。

可见范围与模型库同一把尺子：**公共租户的公开仓库 ∪ 当前租户的仓库**。公开列表未登录也可读。

## 新建技能

点 **+ 新建**，或在地址栏打开 `/new?type=skill`（旧的 `/skills/new` 会重定向到这里）。

表单与代码仓库同构：所有者在左、英文名在右，其余字段纵向排列。创建方式有三种：

| 方式 | 说明 |
|------|------|
| 空仓库 | 创建后在网页或本地用 Git 上传文件 |
| Git URL | 填写源地址，创建完成后自动配置镜像同步 |
| 压缩包导入 | 上传压缩包一次性导入文件 |

**英文名称是路径的一部分，创建后不可更改**，填写时请确认。

提交成功后平台生成 Git 仓库与 `README.md`。

## 详情

进入 `/skills/:namespace/:name`，默认页展示 README、元数据与下载统计。

顶部页签包括 **概览 / 卡片**、**文件** 与 **设置**：

- **文件**：在 Web 界面浏览目录结构与文件内容，也可新建文件或上传。
- **设置**：修改别名、描述、标签与可见性。

## 在智能体里使用技能

在智能体工坊的构建页，「技能」分区的 **添加** 会打开抽屉，左栏按来源分组：

| 分组 | 内容 |
|------|------|
| 平台技能 | 本平台的技能仓库 |
| 内置技能 | 运行时自带的技能 |

分区只列已选的技能，每行可移除。

## 管理后台

管理员可在 **技能管理**（`/admin_panel/skills`）搜索技能仓库，查看可见性与权重，进入详情设置权重或改可见性，并支持单条 / 批量删除。交互与代码管理相同。
