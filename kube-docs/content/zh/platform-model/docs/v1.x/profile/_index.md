## 页面内容

个人主页（`/profile/:username`）展示用户的公开资料与名下资产：

- **资料卡**：头像、昵称、`@用户名`、所属组织；没有数据时显示「暂无数据」。
- **名下资产**：合集、模型、数据集、代码、技能、提示词、用户空间与 MCP。

打开自己的主页可以直接从右上角头像菜单进入；打开别人的主页用 `/profile/:username`。

## 能看到什么

个人主页只展示**你有权限查看**的资产。私有仓库、其它租户的仓库不会出现在这里。
