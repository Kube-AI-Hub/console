## 什么是管理后台

管理后台是行业大模型平台的系统与资产管理入口。以平台管理员身份登录后，从头像菜单进入 **管理员后台**。

后台分成系统、账号、**资产管理** 与 **算力资源管理**。资产管理负责代码、模型、数据集、MCP、用户空间、技能等仓库；**算力资源管理** 下有算力规格管理、运行时框架与镜像管理、公共推理服务。规格页（`space_resources`）负责推理 / 微调 / 开发实例可选的硬件规格，不要和仓库类菜单混用。

Dashboard 与资产管理列表、实例与任务都只显示**当前租户**。切租户后整页刷新，数字必须能对上点进去的列表。规格目录、运行时框架和运营区（同步、云端公共推理）仍是平台级。详见 [列表范围与管理端](../tenancy/lists_and_admin)。
