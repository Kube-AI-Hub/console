## 什么是管理后台

管理后台是行业大模型平台的系统与资产管理入口。以平台管理员身份登录后，从头像菜单进入 **管理员后台**。

后台分成系统、账号与 **资产管理**。资产管理负责仓库类资源；**算力规格管理**（`space_resources`）负责推理 / 微调 / 开发实例可选的硬件规格，两者不要混用。
