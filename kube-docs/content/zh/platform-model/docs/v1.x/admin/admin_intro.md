## 管理入口

以平台管理员身份登录，进入 **管理员后台**。左侧 **资产管理** 与模型、数据集、同步设置在同一组菜单。

| 菜单 | 路径 | 说明 |
|------|------|------|
| **代码管理** | `/admin_panel/codes` | 代码仓库列表、详情、可见性、权重、单条/批量删除 |
| **MCP 管理** | `/admin_panel/mcps` | MCP 仓库同上，列表可看工具数 |
| **用户空间管理** | `/admin_panel/spaces` | 用户空间仓库同上，与算力规格管理分开 |
| **技能管理** | `/admin_panel/skills` | 技能仓库同上 |

**用户空间管理** 管的是用户创建的 Space 仓库。**算力规格管理**（`space_resources`）管的是创建推理实例、微调、开发实例时可选的 CPU/GPU/NPU 规格，不要从用户空间列表去改规格。

模型管理、数据集管理仍在同一组菜单。模型详情支持 **设置权重**（`POST /recom/opweight`）。管理员用户详情 **不提供删除用户**。平台不做技能或其它类型的 GitLab 导入。

## 列表、详情与删除

四类仓库列表均可按名称或所有者搜索。勾选后可 **批量删除**；未勾选时按钮禁用。删除为逐条 `DELETE /{type}/{namespace}/{name}`，没有单独的批量接口。确认框会提示数量，删除过程显示进度。

详情页展示名称、所有者、创建者、可见性、权重、敏感性检查与创建时间。可 **编辑可见性**，或 **设置权重**。

编辑页用开关改公开 / 私有，调用 `PUT /{type}/{namespace}/{name}`，请求体为 `{ "private": true|false }`。

## 新建模型与数据

用户侧新建模型、数据集、代码、技能、MCP、提示词、合集，统一从头像菜单的 **新建模型与数据** 进入 `/new`，再选类型。用户空间、开发实例、组织仍单独留在头像菜单，避免和算力资源混淆。

组织页的「创建」同样收口到该落地页，并保留单独的新建用户空间。各类型列表页的「新建」仍直达对应表单。

| 类型 | 创建方式 |
|------|----------|
| 模型 / 数据集 | 可填写 **Git 源地址**，创建后按源地址建立镜像同步 |
| 代码 / 技能 / MCP | 三选一：空仓库、Git URL 导入、上传本地 zip/tar |
| 提示词 / 合集 | 只走统一入口，不加 Git 或压缩包导入 |
