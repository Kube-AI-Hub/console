## 管理入口

以平台管理员身份登录，从头像菜单进入 **管理员后台**。左侧菜单分成 **系统**、**账号**、**资产管理** 与 **算力管理**。

资产管理负责仓库类资源；**算力规格管理**（`/admin_panel/space_resources`）负责创建推理实例、微调、开发实例时可选的 CPU/GPU/NPU 规格。不要从用户空间列表去改规格。

| 菜单 | 路径 | 说明 |
|------|------|------|
| **代码管理** | `/admin_panel/codes` | 代码仓库列表、详情、可见性、权重、单条/批量删除 |
| **模型管理** | `/admin_panel/models` | 模型列表、新建、详情、别名/来源/权重、同步、行内删除（无批量删除） |
| **数据集管理** | `/admin_panel/datasets` | 数据集列表、新建、来源、单条/批量删除（无管理员详情页） |
| **MCP 管理** | `/admin_panel/mcps` | MCP 仓库同上，列表与详情可看工具数 |
| **用户空间管理** | `/admin_panel/spaces` | 用户空间仓库同上，列表与详情可看许可证 |
| **技能管理** | `/admin_panel/skills` | 技能仓库，交互与代码管理相同 |

管理员用户详情 **不提供删除用户**。平台不做技能或其它类型的 GitLab 导入。

## 代码管理 / MCP 管理 / 用户空间管理

这三类页面共用同一套列表、详情、编辑交互。

### 列表

- **搜索**：占位为「搜索 名称 / 所有者」，输入后约 0.5 秒防抖刷新，可清空。
- **数量徽章**：显示当前筛选下的仓库总数（个代码 / 个 MCP / 个用户空间）。
- **批量删除**：未勾选时禁用。勾选后弹出确认框（确定 / 取消），确认后逐条 `DELETE /{type}/{namespace}/{name}`，过程中显示「正在删除 done/total」。
- **表格列**：名称（外链到前台仓库）、所有者、可见性（公开 / 私有）、权重；MCP 额外显示 **工具数**，用户空间额外显示 **许可证**。
- **行内操作**：**详情**、**删除**（同样有确认，取消不生效）。
- **分页**：上一页 / 页码 / 下一页，每页 10 条。

### 详情

详情页可用左上角返回或面包屑回到列表，字段包括：

| 字段 | 说明 |
|------|------|
| 名称 | 仓库名 |
| 所有者 | 命名空间 |
| 创建者 | 创建账号 |
| 可见性 | 公开 / 私有 |
| 权重 | 运营推荐权重，默认 1 |
| 工具数 | 仅 MCP |
| 许可证 | 仅用户空间 |
| 敏感性检查状态 | 内容检查结果 |
| 创建时间 | `YYYY-MM-DD HH:mm:ss` |

底部按钮：

- **编辑**：进入可见性编辑页。
- **设置权重**：打开对话框，输入整数后可 **取消** 或 **更新**。更新调用 `POST /recom/opweight`，请求体为 `{ "repo_id", "weight" }`。社区版会写入权重，但列表/详情读回时可能仍显示默认值 1。

### 编辑可见性

开关在公开 / 私有之间切换，点 **更新可见性** 调用 `PUT /{type}/{namespace}/{name}`，请求体为 `{ "private": true|false }`。

## 模型管理

列表同样按名称 / 所有者搜索，并显示数量徽章、名称链接、所有者、可见性、权重、**来源**（HuggingFace / ModelScope / 行业大模型平台 / 用户上传）、详情、删除与分页。

与代码管理的差异：

- 提供 **新建模型**，跳转到用户侧 `/models/new`。
- **没有批量删除**，只支持行内删除（取消 / 确定）。

### 模型详情

除通用字段外还有 **模型别名**、**来源**（镜像源地址）。若已建立镜像，还会显示最后更新时间与最后消息。

底部按钮：

- **模型编辑**
- **设置权重**（取消 / 更新，接口同上）
- **同步** / **重新同步**：没有镜像时只提示「请先填写并保存镜像来源后再同步」，不会发起任务
- 若模型开启推理：显示 **新建 Serverless** 或 **Serverless 详情**

### 模型编辑

| 字段 | 可改 |
|------|------|
| 名称 / 所有者 / 创建者 / 敏感性检查 / 创建时间 | 只读 |
| 模型别名 | 可改，保存时不能为空 |
| 可见性 | 开关 |
| 权重 | 数字输入 |
| 来源 | 镜像源地址，保存后创建或更新同步任务 |

点 **保存更改** 后回到详情。别名与可见性走 `PUT /models/{namespace}/{name}`，权重走 `POST /recom/opweight`，来源走镜像创建 / 更新接口。

## 数据集管理

列表按名称 / 所有者搜索，提供 **新建数据集**（跳转到 `/datasets/new`），显示数量徽章、名称链接、所有者、可见性、**来源**、行内删除与分页。

勾选后可 **批量删除**，交互与代码管理相同。数据集管理 **没有** 管理员详情页或编辑页，改仓库信息请到前台数据集页面。

## 新建模型与数据

用户侧新建模型、数据集、代码、技能、MCP、提示词、合集，统一从头像菜单的 **新建模型与数据** 进入 `/new`，再选类型。用户空间、开发实例、组织仍单独留在头像菜单，避免和算力资源混淆。

组织页的「创建」同样收口到该落地页，并保留单独的新建用户空间。模型 / 数据集管理列表上的「新建」直达对应表单。

| 类型 | 创建方式 |
|------|----------|
| 模型 / 数据集 | 可填写 **Git 源地址**，创建后按源地址建立镜像同步 |
| 代码 / 技能 / MCP | 三选一：空仓库、Git URL 导入、上传本地 zip/tar |
| 提示词 / 合集 | 只走统一入口，不加 Git 或压缩包导入 |
