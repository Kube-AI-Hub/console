## 入口

点右上角头像，在下拉菜单选择 **新建模型与数据**，进入 `/new`。

用户空间、开发实例与组织不在本页，它们在头像菜单里单独列出，避免与运行时创建表单混在一起。

## 支持的资源类型

在本页先选资源类型，再在**同一页**完成配置与创建，不会跳转到 `/models/new` 之类的独立表单：

| 类型 | 说明 |
|------|------|
| 模型 | 模型仓库 |
| 数据集 | 数据集仓库 |
| 代码仓库 | 项目代码 |
| 技能仓库 | 供智能体复用的技能 |
| 智能体模板 | 可供委派的智能体定义 |
| MCP | MCP 服务仓库 |
| 提示词库 | 提示词集合 |
| 合集 | 专题聚合，非 Git 仓库 |

## 使用方式

- 点卡片切换类型，表单随类型变化。
- **未提交的内容不保留**：切换类型后已填字段会清空，请在切换前确认。
- 受限账号看不到创建类入口。
