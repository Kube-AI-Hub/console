同一套仓库、用户、实例数据，管理端和前台用不同过滤器。

## 前台 Hub

模型、数据集、代码、技能、MCP、用户空间列表：

- **默认**：其它租户的**公开**仓 ∪ 当前租户的仓，再套现有公开 / 私有权限。切到企业后广场不会只剩本企业私有仓。
- **源过滤「本租户」**：只看当前租户，不再并入其它租户的公开仓。它和「本地」（同步来源）不是一回事。
- 卡片按返回的租户标注 **公共租户**、**本租户** 或企业名。

邀请组织成员时搜索用户**不按**当前企业租户过滤，否则搜不到尚未入组的人。

## 管理后台

以平台管理员身份进入 **管理员后台**。Dashboard 上的账号、资产、运行中实例和算力用量，以及点卡片进去的用户 / 组织 / 资产 / 实例列表，都只统计**当前租户**。界面不提供「全部租户」。

切到公共租户再看 Dashboard：数字应能对上该租户下的列表，不要出现「用户很多、推理却是别的租户在跑」这种混算。

**不算租户范围、仍按平台级展示的：**

- 规格目录、运行时框架与镜像
- Dashboard **运营**（多源同步、云端公共推理）
- 创建实例时可选的集群节点视图（看集群有什么卡，不是租户配额）
