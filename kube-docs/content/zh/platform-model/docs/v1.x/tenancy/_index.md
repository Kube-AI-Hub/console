行业大模型平台的租户等于控制台里的 **租户(企业空间)**，对应 Kubernetes 的 Workspace 资源。平台不另造一套 Tenant CR。开企业、邀请成员、设配额仍在控制台完成；模型广场只负责切换当前租户、把新建资源写进该租户，以及按租户过滤列表。

未加入任何企业、或尚未切换时，当前租户是 **公共租户** `public`。所有登录用户都隐式属于公共租户，不必邀请进 `public`，也不要把公共租户和系统租户 `system-workspace` 混用。

## 对象怎么归属

| 对象 | 租户怎么来 | 能不能改绑 |
|------|------------|------------|
| 组织 | 创建时取当前租户，表单里的所属租户只读 | 不能跨租户改绑；空视为 `public` |
| 个人仓库 | 创建时的当前租户 | 更新仓库不改租户；转到组织时跟目标组织 |
| 组织仓库 | 跟组织已绑定的租户，不被顶栏覆盖 | 随组织 |
| 用户 | **不**绑定单一租户。公共租户统计全部用户；企业租户统计该租户下组织的成员 | 同一人可同时出现在多个租户的统计里 |
| 推理 / 微调 / 开发 / 评测 / 用户空间实例 | 创建时写入当前租户，并挂到所选 **算力项目**（Kubernetes 项目 / 命名空间） | 已有实例不随切换搬家 |

组织管仓库 ACL（公开 / 私有、成员）。Workspace / 项目角色管租户切换、起实例和门户里谁能看见入口。两套成员不要当成一回事。
