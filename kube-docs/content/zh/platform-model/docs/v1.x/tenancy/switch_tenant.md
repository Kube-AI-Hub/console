## 入口

登录后，顶栏语言与头像之间是租户切换器。下拉中始终有 **公共租户**，以及当前用户已加入的企业租户(企业空间)。未登录不显示。

## 怎么切换

1. 打开下拉，选择 **公共租户** 或一个已加入的企业。
2. 页面整页刷新。之后的列表、创建表单和管理后台都按新的当前租户请求。
3. 非法值或未加入的企业会回落到公共租户，不要靠改浏览器存储去伪造企业上下文。

{{< notice note >}}
已有推理、微调、开发实例和评测任务不会跟着切换搬家。它们仍挂在创建时的租户和算力项目上。
{{</ notice >}}

## 创建组织

从头像菜单进入 **新建组织**。**所属租户** 只读，等于当前租户，表单里不能手选。提交后组织绑定该租户，之后不能改到别的租户。

## 创建仓库

模型、数据集、代码、技能、MCP、用户空间：

- 所有者选自己：仓库写入**当前租户**。要落到企业下，先切到该企业再创建个人仓，或把仓放到已绑定该企业的组织下。
- 所有者选组织：仓库跟组织的租户，不被顶栏覆盖。
