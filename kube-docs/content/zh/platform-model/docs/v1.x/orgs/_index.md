## 什么是组织

组织是**共享资产与成员权限的容器**。创建仓库时所有者可以选个人，也可以选已加入的组织；组织内成员按角色获得读 / 写权限。

适合团队共用模型、数据集与代码的场景：资产归组织而不是归个人，成员变动时权限跟着角色走。

## 新建组织

进入 `/organizations/new`。

| 参数 | 说明 |
|------|------|
| 命名空间 | **全局唯一，创建后不可更改** |
| 别名 | 中文名或友好名称 |
| 类型 | 组织类型 |
| 主页 | 组织主页地址 |
| 头像 | 先上传，创建请求只带图片地址 |
| 所属租户 | 只读展示当前租户 |

创建者自动成为组织的初始管理员。重名会被接口拒绝并就地提示。

**所属租户** 由当前租户决定，不是可选的 Workspace 选择器。组织归属租户后不可跨租户改绑。

## 组织首页

进入 `/organizations/:id`，可以看到组织资料与名下的模型、数据集、代码等仓库。

从组织首页可以进入 **成员** 与 **组织 API Keys** 两个页面。

## 成员与角色

成员页（`/organizations/:id/members`）用于邀请成员并分配角色。角色决定写权限：

| 角色 | 说明 |
|------|------|
| 管理员 | 可改组织资料、管理成员、管理全部资产 |
| 成员 | 按角色授予的权限读写资产 |

非管理员打开成员页是只读的。

## 组织 API Key

组织有独立的 API Key，供**自动化代表组织**调用平台接口，而不是代表某个人。明文同样只展示一次，之后只能吊销。

## 可见性

组织归当前租户所有。组织的仓库按仓库自身的可见性对同租户成员开放；其它租户不可见。
