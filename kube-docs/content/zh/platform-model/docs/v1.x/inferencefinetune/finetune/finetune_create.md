## 创建入口

在想要微调的**基座模型**详情页，点击右上角**微调实例**按钮，跳转至创建页面。

{{< notice tip >}}
如果模型详情页未显示"微调实例"按钮，表示该模型当前不支持此功能。请联系平台管理员了解支持情况。
{{</ notice >}}

## 配置参数说明

进入微调实例创建页面后，填写以下配置信息，完成后点击**创建实例**：

| 参数 | 说明 |
|------|------|
| **实例名称** | 自定义名称，不能与已有实例重复，例如：`qwen-medical-finetune` |
| **模型 ID** | 平台中的模型标识，默认锁定当前选择的基座模型 |
| **区域/资源配置** | 根据基座模型规模选择 GPU 规格。页面会显示**推荐最小显存**；规格标称显存低于该值时，卡片标注**显存不足** |
| **算力项目** | 公共租户只能选 **space**；企业租户列出你有权限的项目。微调默认私有，没有公开开关 |
| **运行时框架** | 选择微调框架：**LLaMA-Factory** 或 **MS-Swift** |

## 推荐最小显存

创建页根据模型元数据估算微调所需的最小显存，并与管理员在规格中填写的**显存 (GB)** 对比：

1. **权重显存** ≈ 参数量（十亿）× 每参数字节数（BF16 / F16 为 2 字节）。
2. **微调推荐值** = 权重显存 × **2.0**（覆盖 KV Cache、优化器与运行时开销）。若扫描得到的 LoRA 估算更大，则取较大值。
3. 规格标称显存低于推荐值时，卡片显示**显存不足**。仍可选择该规格，但训练时更容易 OOM。

示例：约 27.78B、BF16 的模型，权重约 55.56 GB，微调推荐约 **111 GB**。

{{< notice note >}}
推荐值仅用于选型参考，不参与 GPU 调度切分。微调比推理需要更多显存余量；若仍出现 OOM，可改用更大规格或启用 QLoRA 等量化微调。
{{</ notice >}}

## 查看实例列表

创建完成后，可通过顶部导航进入**模型训练评测 → 模型微调**实时查看实例启动进度，并管理已开启的微调任务；也可在**资源管理**页面中统一查看。

## 使用微调框架

实例启动后，点击实例名称可进入微调框架界面：

- **LLaMA-Factory**：提供可视化的 LlamaBoard 界面，在页面上选择数据集、配置 LoRA 参数、启动训练，并实时查看 Loss 曲线等训练指标。
- **MS-Swift**：提供命令行和 Web 界面两种方式，支持更多模型类型和量化微调选项。

## 导出微调模型

训练完成后，可将微调权重合并并导出为新的独立模型仓库，用于后续的推理部署或评测。
