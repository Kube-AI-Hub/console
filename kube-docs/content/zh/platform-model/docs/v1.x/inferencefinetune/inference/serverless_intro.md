## 什么是公共推理服务

**公共推理服务**是管理员预置、全平台共享的推理入口。用户无需自己创建实例，即可在 **模型推理 → 公共推理服务** 中打开模型、对话测试或调用 API。

列表同时展示两类公共模型：

| 类型 | 接入方式 | 说明 |
|------|----------|------|
| **本地部署** | 集群内推理实例 | 管理员把平台仓库中的模型部署为共享服务，卡片显示运行时框架和资源配置 |
| **云端 API** | 统一网关转发 | 管理员登记外部厂商通道（如 Moonshot、DeepSeek、阿里云百炼）。卡片显示厂商类型，不占用集群 GPU |

两类模型对用户都走 OpenAI 兼容接口。云端模型经控制台的 `/aigateway`（或 `/platform-model/aigateway`）转发，请求里的 `model` 使用平台模型 ID。

## 与推理实例的区别

| | 公共推理服务 | 推理实例 |
|--|--------------|----------|
| **谁创建** | 平台管理员 | 普通用户 |
| **算力** | 共享本地部署，或使用云端厂商算力 | 用户独占所选规格 |
| **入口** | **模型推理 → 公共推理服务** | **模型推理 → 推理实例**，或模型详情页部署 |
| **鉴权** | 云端通道默认需要访问令牌；本地部署按管理员设置的公开 / 私有 | 创建时选择公开或私有 |

需要独占资源、自定义框架参数或量化档位时，请使用[推理实例](./endpoint_create)。
