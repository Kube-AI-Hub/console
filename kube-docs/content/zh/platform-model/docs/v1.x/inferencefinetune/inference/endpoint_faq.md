## 常见问题

### 部署按钮置灰，提示"推理框架暂未支持该模型"

**原因**：当前推理框架暂时不支持该模型架构。

**解决方案**：请联系平台管理员，告知需要支持的模型名称和相关信息，管理员将评估后尽快添加支持。

---

### 部署按钮置灰，提示"模型 metadata 未识别"

**原因**：模型文件不完整，或模型的配置信息（`config.json` 中的架构信息）暂不支持自动识别。

**解决方案**：
1. 确认模型仓库中包含完整的 `config.json` 文件。
2. 请联系平台管理员，在后台手动触发模型元数据扫描。

---

### 实例长时间处于"启动中"状态

**原因**：可能是算力资源紧张，或模型镜像拉取耗时较长。

**解决方案**：
1. 等待一段时间（大型模型镜像拉取可能需要数分钟）。
2. 如超过 15 分钟仍未启动，请联系平台管理员排查。

---

### 推荐最小显存如何计算？规格为什么显示「显存不足」？

**说明**：创建页按模型参数量和精度估算权重显存，再乘以 **1.5**（覆盖 KV Cache）。若扫描得到的「权重 + KV + 激活」更大，则取较大值。该推荐值与规格上管理员填写的**显存 (GB)** 对比：标称显存更低时卡片显示**显存不足**。

推荐值只用于选型，不参与调度切分。仍可选择标注不足的规格，但更容易 OOM。

---

### 推荐最小显存曾经显示为 1GB

**原因**：部分模型（例如 Qwen3.8 系列）把 `hidden_size` 写在 `config.json` 的 `text_config` 下。旧扫描逻辑只读顶层字段，估算失败后会把推荐值写成 1GB。

**当前行为**：页面会用参数量 × 精度重新推算。例如约 27.78B、BF16 的模型，权重约 55.56 GB，推理推荐约 83 GB。若后台元数据仍是旧值，可请管理员重新扫描模型元数据。

---

### 公共推理服务和推理实例有什么区别？

**公共推理服务**由管理员预置，包含本地共享部署和云端 API 模型，入口在 **模型推理 → 公共推理服务**。需要独占算力、自定义框架参数或量化时，请创建**推理实例**。说明见[公共推理服务介绍](./serverless_intro)。

---

### API 调用返回 401 Unauthorized

**原因**：实例安全级别为**私有**，请求未携带有效的访问令牌。

**解决方案**：在请求头中添加访问令牌：

```bash
-H "Authorization: Bearer <访问令牌>"
```

访问令牌可在平台 **个人设置 → 访问令牌** 中生成。

---

### 创建失败，提示 `engine has no launch.decode`

**原因**：当前运行时框架没有填写 **启动配置（KServe / llm-d）**，或 JSON 中缺少 `decode`（或别名 `template`）。集群开启 KServe 后，推理部署必须配置启动命令。

**解决方案**：管理员在 **管理员后台 → 算力资源管理 → 运行时框架与镜像管理** 中编辑该框架，补上启动配置。说明见 [配置推理引擎](./runtime_framework_admin)。
