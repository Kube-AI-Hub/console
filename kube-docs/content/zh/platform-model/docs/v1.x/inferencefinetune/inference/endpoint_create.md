## 创建入口

在模型详情页，点击右上角**模型部署**按钮，在下拉菜单中选择**推理实例**，跳转至创建页面。

{{< notice note >}}
仅部分模型支持创建推理实例。如果所需模型没有"推理实例"选项，请联系平台管理员。
{{</ notice >}}

## 配置参数说明

进入推理实例创建页面后，填写以下配置信息，完成后点击**新建实例**：

| 参数 | 说明 |
|------|------|
| **实例名称** | 自定义名称，不能与已有实例重复 |
| **模型 ID** | 平台中的模型标识，默认锁定当前模型 |
| **最小 / 最大弹性副本** | 控制副本范围。最小副本为 **0** 时，超过 1 小时无请求将自动关闭 |
| **区域/资源配置** | 选择推理服务的算力规格。页面会显示**推荐最小显存**；规格标称显存低于该值时，卡片标注**显存不足**。规格带**多节点**标签时，副本数固定，且不能自动缩容到 0 |
| **运行时框架** | 先选框架（vLLM、SGLang、TGI、llama.cpp），再选框架版本。多节点推理仅支持 vLLM 与 SGLang |
| **框架参数** | 折叠项。按所选框架版本展示可调参数（如最大生成长度、dtype）。含 `${GPU_NUM}` 的项会按规格每副本卡数展开。未改且不含该占位符的项不写入启动命令 |
| **量化** | 模型仓库提供量化文件时出现，例如 GGUF / AWQ 档位 |
| **安全级别** | **公开**：可任意访问；**私有**：需要鉴权认证 |

## 推荐最小显存

创建页根据模型元数据估算推理所需的最小显存，并与管理员在规格中填写的**显存 (GB)** 对比：

1. **权重显存** ≈ 参数量（十亿）× 每参数字节数（BF16 / F16 为 2 字节）。
2. **推理推荐值** = 权重显存 × **1.5**（覆盖 KV Cache）。若扫描得到的「权重 + KV + 激活」更大，则取较大值。
3. 规格标称显存低于推荐值时，卡片显示**显存不足**。仍可选择该规格，但推理时更容易 OOM。

示例：约 27.78B、BF16 的模型，权重约 55.56 GB，推理推荐约 **83 GB**。

{{< notice note >}}
推荐值仅用于选型参考，不参与 GPU 调度切分。规格上的「显存 (GB)」需由管理员按整卡或切分后的可用显存如实填写。
{{</ notice >}}

## 查看实例列表

创建完成后，可通过顶部导航进入**模型推理 → 推理实例**查看所有已创建的实例及其运行状态；也可在**资源管理**页面的推理实例区块中统一查看。

## 调用推理服务

实例启动后，平台会提供：

- **Web 测试界面**：在浏览器中直接对话测试模型效果。
- **API 接口**：标准 OpenAI 兼容 API，供业务代码调用。

私有实例调用时需在请求头中携带访问令牌：

```bash
curl https://<实例地址>/v1/chat/completions \
  -H "Authorization: Bearer <访问令牌>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<模型名称>",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```
