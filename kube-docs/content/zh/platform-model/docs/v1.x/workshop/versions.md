## 配置即代码

智能体的静态配置保存在它自己的 Git 仓库里：**保存即一次提交**，提交失败即保存失败。配置因此可审计、可比对，也能直接作为模板复用。

## 版本类型

提交说明写明这是什么版本：

| 类型 | 什么时候产生 |
|------|--------------|
| 手动保存 | 人点保存配置或编辑基本信息 |
| 自动养成 | 数字分身在对话中更新了用户档案或经验笔记 |
| 恢复 | 从旧版本恢复 |
| 导入 | 迁移导入，或从卡片用文件替换配置 |

不带前缀的外部提交按手动保存显示。

**自动养成** 在每一轮回复结束后检查：养成文件有变化才提交，没有变化不提交；它也不会让已发布的分身变成「有新修改」。

## 查看版本

在构建页头部点 **版本** 打开下拉面板。每行显示类型标签、说明、短 sha、相对时间、作者，以及「当前」或「已发布」标记和 **恢复** 按钮。列表每页 20 条，可加载更多。

保存时可以填写版本说明；没填时显示「保存 <名称>」。

## 恢复版本

选中一个旧版本点 **恢复**，二次确认后：

- 旧配置作为一次**新提交**写回（`restore: 恢复到 <sha8>（原说明）`），不改写历史，之后的版本都还在。
- 数字分身同时把人设与养成写回容器并刷新配置。

有未保存的修改时，确认框会提示这些修改会丢失。
