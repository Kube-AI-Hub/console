## 发布状态

三种智能体只有三种发布状态：

| 状态 | 含义 | 谁能对话 | API |
|------|------|----------|-----|
| 草稿 | 没发布过，或已取消发布 | 创建者、租户管理员 | 404 |
| 已发布 | 对外版本 = 发布时的提交 | 同租户成员 | 可用 |
| 已发布 · 有新修改 | 发布后又手动保存或恢复过 | 同租户成员（用发布时的版本） | 可用 |

数字分身另有运行状态，与发布状态分开显示。服务专家没有运行状态，创建后即可对话。

## 发布智能体

在构建页头部点 **发布**：

1. 先保存未保存的修改，保存失败则不发布。
2. 打开 **对外发布** 弹窗，包含两块：

**API 调用** 给出调用地址、只显示一次的服务令牌与 curl 示例：

```
POST <站点>/studio-openapi/agents/<key>/invoke
```

请求体为 `{"input": "..."}`，返回 `{id, agent_id, session_id, status, output, elapsed_ms}`。三种智能体返回格式一致。数字分身的调用会转到它自己的容器，容器未就绪时返回 409。

**对话页面** 给出可直接分享的链接与 iframe 嵌入代码：

```
<站点>/studio-preview/chat/<key>
```

对话页面要求登录且同租户，不提供匿名访问；打开后只显示这一个智能体，不能切换或移除。

## 更新发布

发布后又保存过，弹窗会提示对外仍是发布时的版本，此时 **更新发布** 可用；没有新修改时该按钮不可用。

## 取消发布

弹窗左下角可以取消发布。取消后 API 立即返回 404，同租户其他成员不能再对话，对话页面提示未发布；创建者仍可对话。再次发布沿用原令牌。

## 服务令牌

服务令牌只保存哈希，明文仅在发布时展示一次。轮换后旧令牌立即失效。调用方需要自行妥善保存。
