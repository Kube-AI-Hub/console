## 四条入口

工坊左侧 **能力资产** 组提供四条入口，都以**新标签**打开模型平台：

| 菜单项 | 目标页面 |
|--------|----------|
| 技能 | 模型平台技能列表 |
| MCP | 模型平台 MCP 服务器列表 |
| MCP工具 | 模型平台 MCP 工具目录 |
| 智能体模板 | 模型平台智能体模板列表 |

## 为什么不复制

技能、MCP 服务、MCP 工具与智能体模板的**正文**都留在模型平台的 Git 仓库里。工坊只保存引用，不复制第二份仓库。

这样做的直接好处是：能力只维护一份，升级一次即对所有引用它的智能体生效，不会出现两个地方版本不一致。

## 可见范围

四条入口的可见范围与模型库同一把尺子：**公共租户的公开仓库 ∪ 当前租户的仓库**。

进入目标页后能否查看具体内容由模型平台判断。企业租户可以查看公共租户的公开仓库；公共租户的私有仓库与其它企业的仓库会进入未授权页，工坊不另做一套授权页。

## 在工坊里使用这些资产

- **技能**：在数字分身或服务专家的「技能」分区添加。抽屉左栏按「平台技能」「内置技能」分组。
- **MCP 服务与工具**：在「工具」分区的抽屉里切到 MCP 分类添加。切到该分类时平台会自动依次读取每个服务器的可用工具，不用先勾选；勾选一个工具还没读完的服务器时会先读工具，读完再连同全部工具一起选中。
- **智能体模板**：在工作流画布上用 **子智能体** 节点委派到已上传的模板，并限定它的工具与知识范围。
