## 什么是智能体工坊

智能体工坊是行业大模型平台之上的**智能体构建与运营**入口。模型平台解决「模型、数据、代码放在哪」，工坊解决「让模型带着工具、知识和记忆去干活」。

在工坊里，构建者按模式创建智能体，配置人设与能力，在右侧对话区当场验证效果，然后发布给同租户同事使用或通过 API 接入业务系统。整个过程在一个页面内完成，不需要写 YAML，也不需要理解底层的容器与调度。

## 入口

登录 Kube AI Hub 控制台，在顶部产品导航选择 **智能体工坊**，进入 `/studio-preview`。

工坊是独立的页面组，进入后不再显示控制台顶栏；左侧是工坊自己的菜单，右上角保留语言与租户切换。

## 左侧菜单

工坊左侧分为四组：

| 分组 | 菜单项 | 说明 |
|------|--------|------|
| 概览 | 概览 | 数字分身与服务专家两条入口卡片 |
| 我的智能体 | 对话与任务 | 只列出当前用户对话过的智能体 |
| 我的智能体 | 我构建的 | 只列出当前用户创建的智能体 |
| 构建与调试 | 全部智能体 / 数字分身 / 服务专家 | 当前租户内可查看的智能体，按类型筛选 |
| 能力资产 | 技能 / MCP / MCP工具 / 智能体模板 | 以新标签打开模型平台对应列表 |

## 三种模式

创建智能体时先选模式，创建后不可更改。三种模式共用一套卡片、一套发布与版本机制：

| 模式 | 运行方式 | 创建后进入 | 适合 |
|------|----------|-----------|------|
| 数字分身 | 独立的 Hermes 运行容器 | `/studio-preview/digital-twin/:namespace/:name` | 需要长期记忆、定时任务与自主执行的角色 |
| 服务专家 · 标准 | 共享运行时，无需容器 | `/studio-preview/expert/:id` | 一页配完人设与能力即可上岗的岗位助手 |
| 服务专家 · 工作流 | 共享运行时 + 流程画布 | `/studio-preview/orchestration/:id` | 需要多步骤编排或多角色协作的业务流程 |

三种模式都支持统一发布、版本管理与租户隔离。需要多智能体协作时，用工作流模式在画布上放规划节点和子智能体节点，子智能体可委派到已上传的智能体模板。

## 与模型平台的关系

工坊不复制能力资产。技能、MCP 服务、MCP 工具与智能体模板的正文都留在模型平台的 Git 仓库里，工坊只引用。能力只维护一份，升级一次即对所有引用它的智能体生效。

知识库同样来自模型平台，工坊按当前租户检索。
