## 页面范围

`/studio-preview/conversations` 只出现**当前用户对话过**的智能体。服务专家即使不是自己创建的，对话过后也会出现在这里；没对话过的不出现。

已经对话过的会话在取消发布后仍然保留。

## 页面布局

- **上方**：智能体搜索选择器，带头像与「切换智能体」提示。不显示运行时名称。
- **左栏**：页面标题下的 **新建对话** 按钮，下面是占满剩余高度的可滚动会话列表。
- **中间**：当前会话的消息流与输入框。

## 会话管理

同一智能体下可以开多个会话，一件事一个会话。

- **新建对话**：先进入本地草稿态，发送首条消息后才加入列表。
- **编辑标题**：会话 hover 时出现「…」菜单，选编辑后弹窗改名。首轮回复成功后平台会用模型异步总结一个标题；总结失败则回退成第一条用户消息，手工改过的标题不会被覆盖。
- **删除**：同一菜单内删除。

## 消息展示

消息区支持 Markdown、代码高亮、表格、执行过程折叠、工具调用标签与多模态附件。

生成过程中附件与语音按钮禁用，文本框保持焦点，可以接着输入下一条；Enter 在生成结束前不会再发一条。仍可随时切换智能体。

## 定时任务

当前智能体是数字分身时，会话列表下方显示这个分身的定时任务，字段与配置页一致，可以直接暂停和恢复。新建与删除仍在配置页。

容器未就绪时列出上次读到的任务并标明暂时不能改。定时到点运行的结果记在任务上，不另开对话会话。

## 对话权限

- 草稿：只有创建者与租户管理员能新开对话。
- 已发布：同租户成员都可以对话。
- 数字分身尚未启动时提示等待，不丢已输入内容。
