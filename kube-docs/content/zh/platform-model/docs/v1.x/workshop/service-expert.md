## 两种模式

服务专家面向**岗位助手**与**业务流程**，共用一套运行时，创建后模式不可更改：

| 模式 | 页面 | 适合 |
|------|------|------|
| 标准 | `/studio-preview/expert/:id` | 一页配完人设与能力即可上岗的岗位助手 |
| 工作流 | `/studio-preview/orchestration/:id` | 需要多步骤编排或多角色协作的业务流程 |

两类服务专家都没有运行容器，因此没有启动、暂停与上下线，创建后即可对话。

## 标准模式

页面是左配置、右调试两栏。

### 左栏配置

自上而下：

| 分区 | 内容 |
|------|------|
| 模型 | 从当前模型网关列出的模型里选择 |
| 人设与开场 | 人设（Markdown 编辑 / 预览）、开场白、最多 4 条引导问题 |
| 技能 | 从平台技能与内置技能里挑选 |
| 工具 | 内置工具与 MCP 服务器，与数字分身同一套抽屉 |
| 知识库 | 绑定模型平台的知识库 |

人设分区标题右侧是 **根据描述生成**：岗位描述写满 10 个字后可用，生成的草稿弹窗只包含「人设」一块，点 **使用** 后只写回人设，开场白与引导问题保持原样。

### 右栏调试

右栏是对话调试区，包含会话列表、消息流、输入框与 **新对话**。未保存的配置不算已生效，保存后再对话才是当前配置的效果。

### 校验

| 字段 | 上限 |
|------|------|
| 岗位描述 | 500 字 |
| 人设 | 2000 字 |
| 开场白 | 300 字 |
| 每条引导问题 | 60 字 |

名称为空或少于 2 个字时就地提示且不请求接口；超限字段在下方标红。

## 工作流模式

工作流模式打开流程画布，左侧是节点库，分 **基础节点** 与 **能力节点** 两个 Tab。

### 基础节点

18 种编排原语，按用途分组：

| 分组 | 节点 |
|------|------|
| 输入与感知 | 输入、多模态理解 |
| 规划与智能体 | 任务规划、大模型、智能体、技能、子智能体 |
| 知识与上下文 | 知识检索、知识库问答、QA 知识库检索、记忆 |
| 工具与动作 | 工具、代码、报告 |
| 控制与可信 | 条件分支、结果验证、人工审批、输出 |

几个要点：

- **子智能体** 节点可委派到已上传的智能体模板，并限定它的工具与知识范围，用来做多角色协作。
- **条件分支** 按表达式选路，未选中的分支会显示「分支未选中，已跳过」。
- **代码** 节点在隔离沙箱里执行纯计算，访问进程与网络得不到任何东西，死循环按超时中断。
- **QA 知识库检索** 直接返回命中的答案，不调用模型。

### 能力节点

「能力节点」Tab 直接列出已绑定的工具与技能，点一条就往画布加一个已经配好的节点，不用先加空节点再去属性面板里挑。也可以在这里 **新建工具** 或 **新建技能**。

### 配置错误提示

节点配置有误时，三处同时给出同一句话：节点本体画红框并显示第一条错误、属性面板在出错参数下方标红、点运行时被拦下并把画布聚焦到第一个出错的节点。

### 运行与调试

点运行后，调试窗口按节点列出执行结果；某个节点失败时列出原因，点击可把画布选中并居中到该节点。

## 导入与导出

工作流模式支持从卡片 **更多** 菜单导出为平台 JSON、Bisheng、n8n 或 Dify 格式，也支持导入 Dify 工具目录与智能体包。导入替换配置需要二次确认，替换后名称、头像与标签保持不变，旧配置仍可从版本历史找回。
