## 什么是数字分身

数字分身是一个**能自主执行**的智能体：它跑在自己的运行容器里，自己规划步骤、调用工具完成任务，而不是等人工一步步下指令。

适合需要长期记忆、定时任务与自主执行的角色，例如持续跟进客户反馈的销售助理、每天汇总信息的运营助手。

页面不展示用户空间、模板仓库、集群或算力规格——工坊会自行选择运行环境。

## 页面布局

左栏是配置，右栏是调试，撑满内容区。窄屏改为上下叠放。

左栏按分区折叠，默认展开 **基本信息**、**人设与开场**、**技能**，其余折叠。分区标题左侧是折叠箭头，右侧显示已选数量或当前取值。

## 基本信息

头像、名称、描述和标签在头部左侧显示。点名称旁的铅笔打开 **编辑基本信息** 弹窗修改，保存后生成一个新版本。

描述限宽单行显示（1280 以上 480px，以下 340px），悬停可看全文，为空时显示「还没有描述」。

## 人设与开场

**人设** 是这个分身的语气、边界和不能做的事，写成一份 Markdown 文档。编辑区右上角可在 **编辑** 与 **预览** 之间切换，预览按 Markdown 渲染标题、列表、强调与代码；下方显示字数与上限。

人设可由 **根据描述生成** 得到草稿后再手改。同一分区里还有 **开场白** 与最多 4 条 **推荐问题**。

## 能力配置

| 分区 | 内容 |
|------|------|
| 技能 | 从平台技能与内置技能里挑选，抽屉左栏按来源分组 |
| 工具 | 内置工具（按组）与 MCP 服务器聚合在一处，「添加」打开右侧抽屉；切到 MCP 分类会自动读取每个服务器的可用工具 |
| 知识库 | 绑定模型平台的知识库，回答时按命名空间检索 |
| 工作流 | 绑定已有的服务专家工作流 |
| 定时任务 | 让分身按周期自己做事，支持常用频率与 cron 表达式 |

能力类分区只列**已选项**，每行可移除；候选统一在右侧抽屉里搜索勾选，不在页面上平铺。

## 运行模式

运行模式决定分身能自主到什么程度，只有三个单选：

| 模式 | 说明 |
|------|------|
| 观察 | 只读不写，用于先看清它会怎么做 |
| 草稿 | 低风险动作可直接执行，高风险动作由人确认 |
| 半自主 | 放开更多动作，仍保留人工确认的高风险边界 |

切换运行模式会重置工具开关，但不影响已绑定的知识库、工作流与 MCP。

## 养成

**养成** 是这个分身用过之后留下的内容，由它自己在对话中积累，也可以人工查看和修正：

- **用户档案**：它记住的关于你的信息。
- **经验笔记**：它总结的做事经验与教训。

两段都是 Markdown 文档，编辑区同样支持编辑与预览切换。手动保存立即落盘；已经打开的会话仍用会话开始时的快照，下一次新会话才读到改后的内容。

养成内容随容器重建而保留：写入后由容器内的同步循环提交回空间仓库，重起的容器再读回来。

## 调试与 Terminal

右栏有两个页签：

- **对话**：直接和分身对话验证效果。未保存的配置不算已生效。
- **Terminal**：进入分身自己的容器排查问题。容器未就绪时保持禁用并保留已输入内容。

## 容器状态

数字分身有独立的运行状态（运行中、启动中、暂停中、已暂停、运行异常、状态未知），与发布状态分开显示。卡片与配置页都能启动或暂停；运行中只显示暂停，已暂停或异常只显示启动。

容器未就绪时，养成保存、定时任务变更与 Terminal 发送保持禁用，已输入的内容保留。
