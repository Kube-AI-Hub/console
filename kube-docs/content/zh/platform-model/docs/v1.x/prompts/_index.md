## 什么是提示词库

提示词库以**仓库形式**管理一组提示词。先建库，再在库内管理单条提示词。

把提示词集中管理的好处是：同一条提示词可以在多个地方复用，改一次就全部生效，不用在各自的脚本里复制粘贴。

## 库首页

进入 **数据与资产 → 提示词库**（`/prompts/library`）。

- 首页列出当前可见的提示词库，支持按名称检索，分页展示。
- 点击卡片进入库详情（`/prompts/library/:namespace/:name`）。
- 登录且未受限时显示 **新建** 入口。

## 新建提示词库

库英文名是仓库路径的一部分，**创建后不可更改**。其余字段（别名、描述、可见性）与其它仓库同构。

## 库详情与提示词编辑

进入库详情后，页面列出库内的提示词文件。可以：

| 操作 | 说明 |
|------|------|
| 新增 | 在库内新建一条提示词 |
| 编辑 | 打开编辑器修改标题与正文，保存即写回仓库 |
| 复制 | 以现有提示词为模板复制一份再改 |
| 删除 | 移除单条提示词 |

编辑器改的是标题与正文两块，保存后写回该库的 Git 仓库，因此历史版本可追溯。

## 可见性

可见范围与模型库同一把尺子：**公共租户的公开仓库 ∪ 当前租户的仓库**。
