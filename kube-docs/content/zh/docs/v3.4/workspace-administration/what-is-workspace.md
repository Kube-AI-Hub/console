租户(企业空间)是用来管理[项目](../../project-administration/)、[DevOps 项目](../../devops-user-guide/)、[应用模板](../upload-helm-based-application/)和应用仓库的一种逻辑单元。您可以在租户(企业空间)中控制资源访问权限，也可以安全地在团队内部分享资源。控制台文案使用「租户(企业空间)」，API 资源仍是 Workspace，路由仍是 `/workspaces`。

最佳的做法是为业务团队（集群管理员除外）创建新的租户(企业空间)。同一用户可以在多个租户(企业空间)中工作，并且多个用户可以通过不同方式访问同一个租户(企业空间)。

行业大模型平台与控制台共用这套租户。登录用户默认处于 **公共租户** `public`，不必邀请进 `public`，也不要把它和系统租户 `system-workspace` 混用。开企业、邀请成员、设配额在控制台完成；模型广场只提供切换和按当前租户写入。详见 [租户与算力归属](/platform-model/docs/v1.x/tenancy/)。

本教程演示如何创建和删除租户(企业空间)。

## 准备工作

准备一个被授予 `workspaces-manager` 角色的用户，例如[创建租户(企业空间)、项目、用户和角色](../../quick-start/create-workspace-and-project/)中创建的 `ws-manager` 帐户。

## 创建租户(企业空间)

1. 以 `ws-manager` 身份登录 Kube AI Hub Web 控制台。点击左上角的**平台管理**并选择**访问控制**。在**租户(企业空间)**页面，点击**创建**。


2. 对于单节点集群，您需要在**基本信息**页面，为创建的租户(企业空间)输入名称，并从下拉菜单中选择一名租户(企业空间)管理员。点击**创建**。

   - **名称**：为租户(企业空间)设置一个专属名称。
   - **别名**：该租户(企业空间)的另一种名称。
   - **管理员**：管理该租户(企业空间)的用户。
   - **描述**：租户(企业空间)的简短介绍。

   对于多节点集群，设置租户(企业空间)的基本信息后，点击**下一步**。在**集群设置**页面，选择租户(企业空间)需要使用的集群，然后点击**创建**。

3. 租户(企业空间)创建后将显示在租户(企业空间)列表中。

4. 点击该租户(企业空间)，您可以在**概览**页面查看租户(企业空间)中的资源状态。

## 删除租户(企业空间)

在 Kube AI Hub 中，可以通过租户(企业空间)对项目进行分组管理，租户(企业空间)下项目的生命周期会受到租户(企业空间)的影响。具体来说，租户(企业空间)删除之后，租户(企业空间)下的项目及关联的资源也同时会被销毁。

删除租户(企业空间)之前，请先确定您是否要解绑部分关键项目。

### 删除前解绑项目

若要删除租户(企业空间)并保留其中的部分项目，删除前请先执行以下命令：

```
kubectl label ns <namespace> kubesphere.io/workspace- && kubectl patch ns <namespace>   -p '{"metadata":{"ownerReferences":[]}}' --type=merge
```

{{< notice note >}} 

以上命令会移除与租户(企业空间)关联的标签并移除 ownerReferences。之后，您可以将解绑的项目重新[分配给新的租户(企业空间)](../../faq/access-control/add-kubernetes-namespace-to-kubesphere-workspace/)。

{{</ notice >}} 

### 在控制台上删除租户(企业空间)

从租户(企业空间)解绑关键项目后，您可以按照以下步骤删除租户(企业空间)。

{{< notice note >}} 

如果您使用 kubectl 删除租户(企业空间)资源对象，请务必谨慎操作。

{{</ notice >}} 

1. 在租户(企业空间)页面，转到**租户(企业空间)设置**菜单下的**基本信息**。在**基本信息**页面，您可以查看该租户(企业空间)的基本信息，例如项目数量和成员数量。

   {{< notice note >}}

   在该页面，您可以点击**编辑信息**更改租户(企业空间)的基本信息（租户(企业空间)名称无法更改），也可以开启或关闭[网络隔离](../../workspace-administration/workspace-network-isolation/)。

   {{</ notice >}} 

2. 若要删除租户(企业空间)，点击**管理 > 删除租户(企业空间)**。在出现的对话框中输入租户(企业空间)的名称，然后点击**确定**。

   {{< notice warning >}}

   租户(企业空间)删除后将无法恢复，并且租户(企业空间)下的资源也同时会被销毁。

   {{</ notice >}}
