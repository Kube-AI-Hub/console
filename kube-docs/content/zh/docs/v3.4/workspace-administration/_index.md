Kube AI Hub 租户在租户(企业空间)中进行操作，管理项目和应用，而租户(企业空间)管理员负责管理应用仓库。拥有必要权限的租户可以进一步从应用仓库中部署和使用应用模板。他们也可以使用上传并发布至应用商店的单个应用模板。此外，管理员还控制一个租户(企业空间)的网络是否与其他租户(企业空间)相互隔离。

本章演示租户(企业空间)管理员和用户如何在租户(企业空间)层级进行操作。与行业大模型平台的对齐说明见 [租户与算力归属](/platform-model/docs/v1.x/tenancy/)。
