## Page contents

The profile page (`/profile/:username`) shows a user's public details and owned assets:

- **Profile card**: avatar, nickname, `@username`, organization; "No data" when there is nothing.
- **Owned assets**: collections, models, datasets, code, skills, prompts, user spaces, and MCP servers.

Open your own profile from the avatar menu in the top right; open someone else's with `/profile/:username`.

## What you can see

A profile shows only the assets **you have permission to view**. Private repositories and repositories in other tenants do not appear here.
