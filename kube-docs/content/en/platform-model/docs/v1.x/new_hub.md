## Entry

Click the avatar in the top right and choose **New model & data** to open `/new`.

User spaces, development instances, and organizations are not on this page; they are listed separately in the avatar menu so that they are not mixed with runtime creation forms.

## Supported resource types

Pick a type first, then finish configuring and creating it **on the same page**; you are not redirected to a standalone form such as `/models/new`:

| Type | Description |
|------|-------------|
| Model | Model repository |
| Dataset | Dataset repository |
| Code repository | Project code |
| Skill repository | Skills reusable by agents |
| Agent template | An agent definition that can be delegated to |
| MCP | MCP server repository |
| Prompt library | A set of prompts |
| Collection | A curated topic, not a Git repository |

## How it works

- Click a card to switch type; the form changes with it.
- **Unsubmitted content is not kept**: switching type clears the fields you filled, so confirm before switching.
- Restricted accounts do not see creation entries.
