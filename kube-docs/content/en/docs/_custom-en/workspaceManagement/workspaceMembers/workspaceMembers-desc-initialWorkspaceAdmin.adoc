The creator of a tenant (workspace) automatically becomes the tenant (workspace) administrator. Additionally, the **admin** user in the {ks_product-en} platform has all permissions by default in all tenants (workspaces). In the initial state of a tenant (workspace), the above users can invite other users to join the tenant (workspace) and set the roles for these users within the tenant (workspace).
