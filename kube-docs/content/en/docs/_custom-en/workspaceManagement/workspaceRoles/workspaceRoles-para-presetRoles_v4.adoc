Kube AI Hub provides the following preset tenant (workspace) roles:

[%header,cols="1a,4a"]
|===
|Role |Description

|workspace-admin
|Tenant (Workspace) administrator, has full permissions within the tenant (workspace).

|workspace-self-provisioner
|Tenant (Workspace) self-provisioner, can create projects, view tenant (workspace) settings, and has management permissions for projects they create.

|workspace-viewer
|Tenant (Workspace) viewer, can view all resources within the tenant (workspace).

|workspace-regular
|Tenant (Workspace) regular user, only has permission to view tenant (workspace) settings within the tenant (workspace). This role is typically assigned to project members who do not require additional tenant (workspace) permissions.
|===
