The multi-tenant architecture of Kube AI Hub underlies many key components running on the container platform. The smallest tenant unit is the Console **Tenant (Workspace)**, which the Industry AI Model Platform also uses (default public tenant `public`). This chapter outlines the multi-tenant system and how to configure authentication for third-party login. For the Hub side, see [Tenants and Compute Placement](/platform-model/docs/v1.x/tenancy/).
