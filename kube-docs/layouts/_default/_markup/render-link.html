{{- /* Resolve in-repo relative links to real permalinks. The docs use pretty URLs, so every page is served from its own directory (`/index.html`). A markdown link written as `./sibling` therefore resolves against `/`, one level too deep, and lands on the SPA 404 shell; `../sibling` has the same problem from the other side. Resolving the destination through `.Page.GetPage` yields the permalink the page actually lives at, so the link works regardless of how the source spelled it. Anything GetPage cannot resolve (external URLs, anchors, files that are not pages such as images) is left exactly as written. */ -}} {{- $dest := .Destination -}} {{- $href := $dest -}} {{- if or (hasPrefix $dest "./") (hasPrefix $dest "../") -}} {{- $lookup := $dest -}} {{- if hasPrefix $dest "./" -}} {{- $lookup = strings.TrimPrefix "./" $dest -}} {{- end -}} {{- with .Page.GetPage $lookup -}} {{- $href = .RelPermalink -}} {{- end -}} {{- end -}} {{ .Text }}
