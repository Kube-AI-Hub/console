## 本次整合

- 取消路线/区域方案里复制的页面数量、旧 TODO 和逐轮进度，以能力矩阵为唯一复核任务入口。
- 将旧“有路由就已迁移”“新 PRD 自洽就完整”“先功能后视觉”的口径改为同批五项验收。
- 提供独立于新 PRD 的旧能力表、数据链路、视觉基线与证据状态模板，不新增另一份全站手写报表。
- 旧方案的长期有效经验归入迁移指南/区域方案；原批次文件只作证据，不继续增长“下一轮”建议。
- 过期能力矩阵和旧对照表默认折叠，当前待办与方法先呈现，避免读者直接沿用旧“仍缺/不做”结论。
- 更正生成器归属、ID 重复检查及验证范围的说明；不改生成器或绕过已有门禁。
- 清除旧环境说明中的明文登录凭据；凭据不应成为历史文档的一部分。

## 维护规则

每次交付只更新目标 PRD/design/spec、该页交付记录及能力矩阵对应行。
结构变化才改 `tree.py`/区域注册表；生成物用脚本更新，不手改。
执行路线只在优先级或流程变化时改，不再逐轮追加进度；区域方案不存瞬时故障和测试总量。
新历史记录应包含日期、提交/构建、验证范围及后继链接，不以“最后更新较新”冒充现行方案。
旧版 Docker、协作、国际化和后端接入说明仍保留原用途，不作为新 UI 迁移的起步命令。
