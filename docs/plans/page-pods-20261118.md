## 4. 交互、视觉与复用基线

| 项 | 编码前约定 | 验证断言/截图 |
| --- | --- | --- |
| 信息层次 | 列表首屏回答「哪些容器组不正常」：状态与原因比创建时间更靠前；详情首屏是概览，调度信息是第二个页签（旧页顺序：资源状态→调度信息→元数据→监控→环境变量→事件） | 首屏 + 全页；页签顺序与旧页对照 |

| 字号层级 | 页签名与区块标题同一层级（`text-sm font-medium`），属性标签与值同尺寸、值次色；**关系**：区块标题不小于正文，属性值不放大 | 关系断言，不钉类名 |
| 密度与铺满 | 环境变量卡片铺满内容列；状态信息四项条件两列栅格；容器监控四图两列 | `getBoundingClientRect()` 差值 |

| 图标与图表 | 条件状态用徽标而非图标文字；容器监控用 `TrendChart`（多序列能力已有），**不得**用数字卡替代 | 图表存在且有点；空态文案 |
| 通用控件 | `Tabs` 用页面既有 `Button + role=tab` 形态（ui 包未导出 Tabs）；列表筛选用 `ResourceList` 的 filter 控件；卡片用现有 section 样式 | 无新增私有控件 |
| 表单与弹窗 | 本批无新表单；日志/终端弹窗沿用既有 | 键盘/焦点 |
| 链接与状态 | 节点列 → 节点详情；GPU uuid → 该节点 GPU 状态页；容器名 → 容器详情 | 全部入口实际走通 |
| 空态四要素 | 环境变量空态、监控空态、无原因、未调度各有独立文案 | 文案不同且可区分 |
| 控制台（适用时） | 沿用既有 `ExecConsoleDialog`（首次输出才算就绪、Esc 留给程序） | 本批不改 |
