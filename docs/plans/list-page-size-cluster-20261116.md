## 2. 修掉的两个真实缺陷

1. **页大小没进 queryKey**（六个集群列表）：选择器接上后 `pageSize` 变了但键没变，react-query 直接返回缓存——
   表现为「选择器显示 50、表格还是 20 行、没有新请求」。页大小与页码一样是查询的一部分。
2. **客户端分页不切片**（集群存储类）：一次取全量再本地排序，分页器是客户端的，但表格把全部行都画出来，
   页码按钮点了没反应。现在按 `page/pageSize` 切片，并把两者放进 `useMemo` 依赖。
