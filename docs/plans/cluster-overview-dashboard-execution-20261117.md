# 集群概览交互仪表盘优化记录

## 范围与实现

本批只优化集群概览及其kubectl启动链路，不重新分析其他待迁模块。
采用用户确认的两张参考融合：资源总量/用量优先、节点排行随后，基本信息和Kubernetes状态放在辅助区且相邻可见。
默认30秒协调更新，可暂停、隐藏时暂停；一次点击原地打开近全屏kubectl。
本地5178构建经8092 BFF读取B200，旧站为console-dev同host同账号。
未部署生产，未切GPU模式、修改设备插件、创建工具Pod或安装编辑器。

## 新增交互与公共组件

- `OverviewResourcePanel`统一六类资源、选择状态、时间窗及真实历史。
  GPU显存默认，无GPU默认CPU；只查询选中资源的usage/total，按时间戳配对。
  节点统计位于排行左侧约1:2，基本信息/Kubernetes状态对齐该左栏。
  按用户最新要求仅保留节点总量、就绪数量和就绪率，禁用节点历史请求并移除其图表/时间窗。
- `useOverviewRefresh`是唯一协调器，阻止请求重叠，隐藏暂停和离开清理。
  按最新要求移除“最近刷新”显示；暂停/继续及刷新使用图标文字ghost按钮，kubectl为primary主按钮。
  自动刷新周期通过提示和可访问名称说明，手动刷新有loading反馈；失败保留旧值时标记旧值。
- 常用运维入口四项统一secondary Button，两列同宽同高、图标及文字左对齐。
  导航项使用asChild Link；补修公共Button的Slottable组合错误，并新增2条测试和Storybook导航示例。
- ai-kit新增`MetricRing`；`TrendChart`新增可选轴/网格/面积/采样读数与键盘交互。
  原props默认行为保留，无数据不造波动，缺口面积独立闭合，超配文本不截断。
- `KubectlConsoleDialog`统一目标查询、准备态和连接，当前用户/集群/实例独立缓存，
  关闭取消，晚到响应不重开，403不重试。原工具页共用控制器但不自动启动。
- 环图和交互趋势补Storybook；局部减弱动画样式修复后必须重新构建再复跑，
  不删掉减弱动画断言。
