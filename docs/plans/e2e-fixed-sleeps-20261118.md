## 为什么值得处理

| 问题 | 后果 |
| --- | --- |
| sleep 太短 | 偶发失败，被当成产品回归重跑 |
| sleep 太长 | 单条用例白等数秒，整套慢几分钟 |
| 两者叠加 | 测试既慢又不可信，正是「验证时间变长」的来源之一 |
