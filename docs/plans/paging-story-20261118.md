# 分页与每页条数：在 Storybook 上验（2026-11-18）

每页档位是 32 个服务端分页列表共用的能力，规则有两条：翻页正确、**切换每页条数回到第一页**。

## 实测（`Schema/ResourceList › refresh and paging`）

```
page 1:              1/20/73
点「下一页」:         21/40/73
每页选项:            ['10', '20', '50', '100']
在第 2 页选 50 条:    1/50/73        ← 回到第 1 页
```

## 对应规则

| 规则 | 实测 |
| --- | --- |
| 翻页取到下一段 | 1-20 → 21-40，总数 73 不变 ✓ |
| 每页档位来自 schema | 四项 10/20/50/100 ✓ |
| 切换每页条数回到第一页 | 第 2 页选 50 → 显示 1-50 ✓ |

## 一处踩坑

`get_by_role('button', name='20')` 找不到每页触发器（可访问名与文本不完全一致），改用 `locator('button', has_text='20')`。
**按 role+name 找不到时，退一步按文本找，再不行 dump 结构**——这个顺序比逐个猜快。
