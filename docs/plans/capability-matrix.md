## 4. 怎么维护这份矩阵

1. **补一个页面**：在 §2 加一行，四列都填；任一列写「部分」必须在 §1 或 `page-parity-report.md` 里能查到理由。
2. **补一个能力**：把对应格子从「部分」改成 ✅，并在 §1 的对应 R 条目上标「已补 + commit」。
3. **改判定**：先在 PRD「明确不做」与 design 的 DEC 里改，再回来改这里——**顺序反了就会变成两份互相矛盾的记录**。
4. **每轮收尾**：`gap_check.py` 的汇总行（页面级）+ 本文件的归宿统计（能力级），两行一起贴。
