# 应用实例详情：集群归属的第二处修正（2026-11-16 第 64 轮）

## 1. 本轮修的

上轮修了「资源页签把 OpenPitrix runtime id 当集群名」，本轮把同一根因的**显示层**也修了：
基本信息里的「集群」一行原来显示 `release.cluster`（即 runtime id `default`），现在显示控制台集群。

实测两条路由（项目级与工作空间级实例页）：

```
名称 | tc-colvis-79029302 | … | 项目 | default | 集群 | host | …
```

工作空间级路由不带 `cluster` 参数，回落到 `host`——本部署只有一个集群，行为正确。

## 2. 全仓复查

把所有 `release.cluster` / `runtime_id` 的用法列了一遍，只有两处：

| 位置 | 状态 |
| --- | --- |
| `InstalledAppDetailPage` 资源查询 | 上轮已修（用路由的 cluster） |
| `InstalledAppDetailPage` 基本信息「集群」行 | 本轮已修 |

`toInstalledRelease` 里保留 `runtime_id` 映射，并在注释里写明它**不是**集群名，避免下一个人再踩。

## 4. 反思

| # | 规则 | 触发事故 |
| --- | --- | --- |
| 1 | **修一个缺陷后，把同一根因的其它用法一次查完** | 上轮只修了资源查询，显示行还留着同样的错误值 |
