## 1. 旧能力与归宿

| 旧能力 | 归宿 | AC / 用例 |
| --- | --- | --- |
| 规则表可搜索（名称/表达式/摘要） | **补齐**：客户端过滤，匹配名称、表达式、摘要、说明与级别，不区分大小写 | AC-RULES-09；TC-RULES-09 |
| 规则表分页 | **补齐**：每页 10 条 + 「第 x-y 条，共 N 条规则」+ 上一页/下一页；N ≤ 10 不渲染分页器 | 同上 |
| 搜索无结果的呈现 | **补齐**：显示「没有匹配「关键字」的规则」，而不是空表 | 同上 |
| 搜索后回到第 1 页 | **补齐**：关键字变化时 `setPage(1)` | 同上 |

## 2. 实现要点

- 搜索与分页都在客户端：规则随规则组对象一起返回（`spec.rules`），再发一次请求只会更慢。
- 字段名以 mapper 为准：`RuleGroupRule` 是 `name`/`expression`/`summary`/`message`/`description`/`severity`，
  不是 CRD 的 `alert`/`expr`——按 CRD 取名会让搜索永远无匹配（本批踩到并修掉，记为 GOT-09）。
